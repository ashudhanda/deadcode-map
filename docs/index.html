deadcode-map. web checker

Paste a public GitHub repo link. See its dead code, file by file, right here.

Lightweight browser analyzer. This page runs a regex-based analyzer in your browser — it is not the full tree-sitter CLI, so it can miss exotic syntax and it cannot run your tests (--prove). For full accuracy, use the CLI: github.com/ashudhanda/deadcode-map. Public repos only. Nothing is uploaded anywhere — files are fetched from GitHub and analyzed in your browser.

Example: https://github.com/ashudhanda/deadcode-map — a /tree/branch/path link works too.

Without a token, GitHub allows 60 API requests per hour. Your token is never stored — it is sent only to api.github.com, in memory, for this one check. Leave it empty to stay anonymous.
